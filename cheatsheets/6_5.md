## Microcontrollers & Signal Conditioning

- **Microcontroller architecture:** Integrated IC housing CPU, Flash ROM (program memory), RAM (volatile variables), EEPROM, Timers, ADC, and GPIO pins (e.g. PIC, ATmega, ARM Cortex).
- **Analogue-to-Digital Conversion (ADC):** Samples continuous analogue input voltages (0–5V) into discrete digital integers. A 10-bit ADC provides ^{10} = 1024$ quantization levels ( \\to 1023$); voltage step size $= \\frac{5\\text{V}}{1023} \\approx 4.88\\text{ mV}$.
- **Pulse Width Modulation (PWM):** Varying the ratio of on-time to off-time in a high-frequency square wave (Duty Cycle $\\% = \\frac{t_{on}}{t_{period}} \\times 100\\%$) to smoothly vary average power delivery to DC motors and heaters.

## Control Logic & Closed-Loop Feedback

- **Closed-loop feedback control:** Continuously measures system output via sensors, subtracts output from desired target setpoint to derive error ( = \\text{Setpoint} - \\text{Sensor Feedback}$), and applies correction.
- **PID controller components:** Proportional (responds to current error magnitude), Integral (accumulates historical steady-state error), Derivative (anticipates future error rate of change).
- **Flowchart programming conventions:** Explicit decision diamonds checking sensor threshold limits, branch logic, loops, and digital pin writes.
